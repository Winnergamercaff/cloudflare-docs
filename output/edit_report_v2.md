## การตัดต่อ v2

- **ช็อต 1–3** ใช้ตาม v1 ทุกอย่าง รวมถึงการตัด dissolve ที่มีภาพซ้อน แต่ยกเลิก fade-out ท้ายช็อต 3 แล้วตัดตรงเข้าช็อต 4 ภาพพระเดินจากไปในหมอกต่อกับพระเดินในป่าได้ต่อเนื่อง
- **ช็อต 4–8** คงไว้เต็มช็อต เพราะไม่พบเทคซ้ำหรือภาพเสีย และแต่ละช็อตมีบทพูดหรือจังหวะสร้างความตึงเครียดเกือบตลอด ช่วงเงียบในช็อต 5 (0–8.6 วินาที) เป็นการปูอารมณ์ก่อน stinger จึงไม่ตัด
- **ตอนจบ:** บทพูดสุดท้ายยาวถึง 9.9 วินาทีของช็อต 8 จึงค้างเฟรมสุดท้าย 1.5 วินาที (ภาพพระนั่งนิ่ง) แล้ว fade out 1.5 วินาที เพื่อไม่ให้ fade กลบคำสุดท้าย
- **ภาพ:** ไม่ปรับสี โทนเปลี่ยนจากรุ่งเช้าเป็นป่าหมอก แล้วเป็นกลางคืนที่มีแสงตะเกียง ซึ่งเป็นไปตามเรื่อง
- **เสียง:**
  - gain รายช็อต: ช็อต 4 = 0 dB, ช็อต 5 = −3 dB (ลด stinger), ช็อต 6 = −4 dB, ช็อต 7 = −3 dB, ช็อต 8 = −4 dB เพราะบทพูดในช็อต 6–8 ดังกว่าช็อต 2 ราว 5 dB
  - ใช้ chain เดิมจาก v1 แต่ตั้ง true peak เป็น −2.0 dBTP เพราะในตัวอย่าง ช่วงช็อต 3 มีพีคขึ้นไปถึง −0.3 dBTP

## การถอดเสียง — ปรับปรุงจาก v1

v1 ใช้ sherpa-onnx ถอดเสียง ซึ่งทำให้ตัวอักษรไทยบางตัวหาย (เช่น «รรม», «เ่า») เพราะแปลง token ทีละตัวเป็นข้อความ ตัวอักษรไทยที่ไบต์ถูกแบ่งอยู่คนละ token จึงหายไป

v2 เขียนตัวถอดรหัส Whisper large-v3 เอง โดยต่อไบต์ของ token ก่อนแปลงเป็น UTF-8 ผลคือได้ตัวอักษรครบ และ**ยืนยันคำที่เติมเองใน v1 ได้แล้วว่าถูกต้อง** คือ «ธรรม» และ «เท่า» รวมถึง «เจ้า» และ «เพราะ» ในช็อตใหม่

## ผลตรวจคุณภาพ `final_v2.mp4`

**ตรวจอัตโนมัติ**

- ถอดรหัสได้ครบทั้งสองไฟล์ ไม่มี error
- ภาพและเสียงเริ่มที่ 0.000 และยาว 81.000 วินาทีเท่ากัน
- Integrated −16.0 LUFS, LRA 11.3 LU, True Peak −1.8 dBFS
- Loudness รายช่วง:

| ช่วง | ช็อต | LUFS |
|---|---|---|
| 0–9.5 | 1 | −16.1 |
| 9.5–19.5 | 2 | −15.3 |
| 19.5–29.5 | 3 | −18.4 |
| 29.5–39.5 | 4 | −17.3 |
| 39.5–49.5 | 5 | −21.3 (ช่วงเงียบโดยตั้งใจ) |

- blackdetect พบภาพดำเฉพาะ 80.75–80.96 ซึ่งเป็นปลาย fade-out ตามตั้งใจ
- freezedetect ไม่พบภาพค้างผิดปกติ เฟรมที่ค้างท้ายเรื่องมี fade ซ้อนอยู่ จึงไม่ถูกนับว่าค้าง

**ตรวจด้วยตาจากเฟรมที่ดึงออกมา**

- รอยต่อทุกจุด (29.5, 39.5, 49.5, 59.5, 69.5) ไม่มีเฟรมเสีย
- ซับใหม่ทั้ง 8 cue แสดงสระและวรรณยุกต์ถูกต้อง รวมถึงตัวเอียง ไม่ตกขอบ

**ข้อจำกัดของการตรวจ:** ไม่ได้ฟังด้วยหูจริง เพราะเครื่องนี้เล่นเสียงไม่ได้

## จุดที่ยังต้องทบทวน

1. **ชื่อในช็อต 6 ว่า «พระภาวิน»** และ **คำว่า «นี้» ในช็อต 7 «เจ้านี้ออกมาบวช»** ยังไม่แน่ชัดจากเสียง ถ้ามีบทพูดที่ใช้สั่งสร้างคลิป กรุณาส่งมา หรือแก้ `text` ใน `edit_timeline_v2.json` แล้วเรนเดอร์ใหม่
2. **ช็อต 8 «นี่คือความ… ไม่ใช่ความจริง»:** ถอดได้เพียงเท่านี้ อาจมีคำหลัง «ความ» ที่ตัวถอดเสียงจับไม่ได้ ส่วน 0.4 วินาทีสุดท้าย (ผมหมด/หมหมด) ไม่ได้ใส่ซับ
3. **ความต่อเนื่องของภาพจาก AI:**
   - กลดเปลี่ยนจากมุ้งผ้าสีครีม (ช็อต 5–6) เป็นกระโจมพลาสติกใส (ช็อต 8)
   - ช็อต 7 พระนั่งกลางป่าโล่ง ไม่อยู่ในกลด
   - ช็อต 8 ช่วง 3.5–4.3 มีก้อนควันดำที่ดูเป็น artifact
   - แก้ด้วยการตัดต่อไม่ได้ ต้องสร้างช็อตใหม่
4. **Stinger ท้ายช็อต 5** ยังดังกว่าส่วนอื่นแม้ลดไปแล้ว 3 dB และผ่าน limiter ซึ่งเป็นความตั้งใจแบบ jump scare ถ้าต้องการให้เบาลง ปรับ `audio_gain_db` ของ segment F
5. **ป้ายไม้ในช็อต 2:** ตัวอักษรไทยที่ AI สร้างผิด (ปัญหาเดียวกับ v1)
